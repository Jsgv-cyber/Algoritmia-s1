El proyecto se llama Algoritmia-s1 se divide entre los Codigos psc que son los codigos creados para cada problemas y que ejecutan una accion espesifica, luego esta la carpeta Diagramas que
se compone de esos mismos codigos de la carpeta psc pero en formato diagrama de flujo para explicar de manera grafica su funcionamiento.
procedere a explicar los algoritmos, haciendo la aclaración de que dado a que algunos de estos son silmilares tanto por el nombre como por función, los agrupare y explicare sus diferencias:


1. Saludo: Es uno de los algoritmos mas sencillos, unicamente consta de escribir un nombre y el algoritmo se encarga de saludar a dicha persona con el nombre puesto.

2. EdadEnDias: Este algoritmo fue creado pensando en traducir la edad de alguien multiplicando los 365 dias del año por la edad que ingrese.

3. ValidarPin: Un algoritmo de repetir, consiste en que la aplicación pide un numero de 4 dígitos específico, ósea el pin se tienen 3 intentos y si después de estos no se acertaba con el numero la aplicación decía "tarjeta bloqueada" pero si acertaba decía "bienvenido".

4. Pirámide: Es un algoritmo basado en la escalera de asteriscos pero ahora dispuestas de tal forma para que cuando ingreses un numero los asteriscos se disponen en funcion de filas de arriba a bajo formando una pirámide completa.

5. PromedioNotas y CompararCalificaciones: Los dos tienen como tema central el calificar notas pero difiere en el propósito y la ejecución, mientras PromedioNotas se basa en pasarle 3 calificaciones de entre 0 a 5.0 para luego con base en lo que le diste promediar si se aprobó o no , el de CompararCalificaciones consiste en tomar las calificaciones de 5 estudiantes y determinar la menor la mayor y quien no aprobo.

6. ValidarRegistro: Es un algoritmo que guarda datos como la edad, los términos y condiciones y si se cumplen ciertos parametros el aplicativo dice "registro exitoso".

7. ElAñoBisiesto: Este es un algoritmo sencillo para determinar si un año es bisiesto o no, si el año se divide entre 4 sin dejar decimales entonces es bisiseto.

8. Semáforo: Con este se asignan colores a los números si es un numero negativo marca error, 0 es igual a rojo, entre 1-10 es amarillo y mayor a 10 es verder.

9. OrdenamientoBurbuja: Este Algoritmo permite ordenar una secuencia de números (que debe ser entre 1 a 100) de menor a mayor, primero se dice cuantos números se quieren ingresar después se procede a ingresar dichos números y el algoritmo muestra la lista y los ordena de menor a mayor.

10. CajeroDeParqueadero, CobroDeParqueadero y Parqueadero: Tres algoritmos con el fin de comprobar el cobro en un parqueadero, cada uno operando bajo lógicas diferentes y problemas diferentes a resolver. En CajeroDeParqueadero simplemente se ingresa un numero y se sigue hasta que se use el 0 para cerrar y dependiendo de los números y las veces que se pusieron antes del 0 se decide el valor del cobro. En CobroDeParqueadero ya se incluye un tiempo estipulado que debe ser ingresado, si la estadía del vehículo no supera este tiempo no se genera cobro, si la estadía lo sobrepasa entonces dice "Excediste el tiempo gratuito permitido" y cobra $ 4.000. Finalmente el algoritmo simplemente llamado Parqueadero es el mas elaborado de los 3 puesto que este evalúa tipo de vehículo, tiempo de estadía si poseen el comprobante, se tiene una tarifa estándar dependiendo del vehículo y revisando cuanto tiempo de mas estuvo parqueado se le suma a dicha tarifa.

11. Propinas y LaFactura: " algoritmos con el fin de revisar el cobro por una orden de un restaurante. En Propinas se ingresa el  valor de la cuenta , el porcentaje de la propina y cuanta gente estaba presente para sacar las cuentas de lo que le toca pagar a cada uno, en LaFactura se establecen unos platos con sus respectivos precios Bandeja Paisa: $25.000, Ajiaco: $12.000 y Sancocho: $18.000. y dependiendo de la elegida al precio se le saca el subtotal, el impuesto y la propina para tener el total apagar al final.
